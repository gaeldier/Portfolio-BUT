Algorithme d'Appariement 🤝

Développement d'une application Java pour gérer les échanges scolaires internationaux. Le but est de créer des paires "Hôte / Visiteur" basées sur un score de compatibilité.

Critères de compatibilité

L'algorithme calcule un score d'affinité basé sur :

  • 🥗 Régime alimentaire (Végétarien, Halal, etc.)
  • 🐶 Allergies aux animaux
  • 🎨 Hobbies (Score pondéré)
  • 📅 Historique (Éviter les répétitions)

Architecture Technique

Le projet suit une architecture stricte avec séparation des responsabilités[cite: 180]:

  • CSVReader/Writer : Gestion de la persistance des données.
  • AdolescentsArray : HashMap optimisée pour gérer les paires.
  • Serializer : Sauvegarde binaire de l'état de l'application.
