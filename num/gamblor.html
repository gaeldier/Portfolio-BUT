Gamblor - Simulation de Casino 🎰

Un jeu de gestion et de hasard en ligne de commande. Le joueur doit gérer son argent mais surtout son niveau de stress pour ne pas faire une crise cardiaque.

Mécaniques de Jeu
🎲 Jeux de Hasard

Machine à sous (Slots) et Roulette fonctionnelle avec gestion des paris.

❤️ Gestion du Stress

Jauge vitale. Si le stress atteint 100%, c'est Game Over. Les gains réduisent le stress, les pertes l'augmentent.

🛒 Boutique & Inventaire

Achat de consommables (Café, Cigarette, Pizza) pour gérer le stress ou Marché Noir (Reins, Sang) pour l'argent.

💾 Sauvegarde

Système de sérialisation binaire (.kar) pour sauvegarder la progression du joueur.

Snippet : Gestion des Événements Aléatoires

Le jeu inclut un système d'événements (trouver de l'argent, accident, etc.) qui se déclenchent aléatoirement tous les X tours.

public void consequenceEvent(Events e, Joueur j){ if (e.equals(Events.MORT_GM)){ j.addWallet(100); System.out.println("Héritage : Vous gagnez 100$"); } else if(e.equals(Events.VOITURE)){ j.addStress(20); System.out.println("Accident : Votre stress monte de 20"); } else if(e.equals(Events.REDUC)){ this.reduc=true; System.out.println("Promo : Prochain tirage moitié prix !"); } // ... gestion des autres événements }
