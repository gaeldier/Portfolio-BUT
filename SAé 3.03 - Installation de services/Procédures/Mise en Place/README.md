# 🖥️ Mise en Place de l’Environnement
---

## Objectif
Ce guide explique étape par étape comment préparer l'environnement (SSH, création de machine virtuelle, configuration réseau, mise à jour) afin d'installer ensuite Matrix (Synapse) et Element.

## Pré-requis
- Un compte étudiant fourni par l'IUT (identifiants pour dattier.iutinfo.fr).
- Une machine physique. 
- Connexion réseau à l'IUT.  
- Un éditeur de texte en ligne de commande (ex : `nano`, `vim`).
