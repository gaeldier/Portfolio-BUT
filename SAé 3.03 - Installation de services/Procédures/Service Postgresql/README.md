# 🗃️ Installation du Serveur de Données
---

## Objectif
Cette partie explique comment installer et configurer PostgreSQL afin de l’utiliser comme base de données pour Synapse.

À la fin de cette procédure, nous serons capable de :
- vérifier que PostgreSQL fonctionne correctement
- créer des utilisateurs et des bases de données
- nous connecter à PostgreSQL en TCP
- comprendre les fichiers de configuration essentiels
