## Commandes :

- **cd** : "Change Directory", permet de changer le répertoire de travail actuel.
- **ls** : "List", permet de lister les fichiers et répertoires dans le répertoire courant.
- **pwd** : "Print Working Directory", affiche le chemin complet du répertoire de travail
- **echo** : "Echo", affiche une ligne de texte ou une variable dans le terminal.
- **rm** : "Remove", permet de supprimer des fichiers ou des répertoires
- **cp** : "Copy", permet de copier des fichiers ou des répertoires d'un emplacement à un autre.
- **mv** : "Move", permet de déplacer ou renommer des fichiers ou des répertoires.


## Expressions :

###  **>** 
"Rediriger la sortie", permet de rediriger la sortie standard d'une commande vers un fichier ou une autre commande. le symbole `">"` est utilisé pour écraser le contenu du fichier existant.

###  **>>** 
"Rediriger la sortie vers", permet de rediriger la sortie d'une commande vers un fichier ou une autre commande. le symbole `">>"` est utilisé pour ajouter la sortie à la fin d'un fichier existant, sans l'écraser.

###  **|** 
"Pipe", permet de rediriger la sortie standard d'une commande vers l'entrée standard d'une autre commande.

###  **&&** 
"Et logique", permet d'exécuter une commande uniquement si la commande précédente a réussi (retourne un code de sortie 0).

###  **||** 
"Ou logique", permet d'exécuter une commande uniquement si la commande précédente a échoué (retourne un code de sortie différent de 0).

###  **;** 
"Séparateur de commandes", permet d'exécuter plusieurs commandes successivement, indépendamment du succès ou de l'échec des commandes précédentes.

###  **&** 
"Exécution en arrière-plan", permet d'exécuter une commande en arrière-plan, permettant à l'utilisateur de continuer à utiliser le terminal pendant que la commande s'exécute.
